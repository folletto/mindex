Mindex

A catalogue of your things, kept in a folder you own.

Mindex keeps a list of items — tools, parts, equipment, whatever you need to find again — with notes, your own custom fields, and the manuals and photos that go with them. It runs entirely on your machine. There is no account, no server, and nothing to sign up for.

    Everything lives in one folder

    You pick the folder on first launch. Inside it, Mindex keeps a small database file and one subfolder per item holding that item's attachments: 

    My Catalogue/
├─ catalogue.db
├─ data/
│  ├─ acme-widget-mk2/
│  │  ├─ datasheet.pdf
│  │  └─ photo.jpg
│  └─ bosch-gsb-13-re/
│     └─ manual.pdf
└─ deleted/

    Put that folder in Dropbox, iCloud or Syncthing and several machines can share one catalogue. Open it in Finder or Explorer and everything is where you would expect. Stop using Mindex tomorrow and your files are still just files.

    Deleting never destroys anything

    Moving an item to the trash moves its folder into deleted/ with a timestamp. Nothing is removed from disk — if you want the bytes gone, you delete them yourself, deliberately, in your file manager.

    Installing

    macOS

    Builds are currently unsigned, so the first launch needs a right-click on the app and then Open — double-clicking will show a warning and refuse. You only have to do this once. If macOS still refuses: 

    xattr -d com.apple.quarantine /Applications/Mindex.app

    Windows

    SmartScreen will warn about an unrecognised publisher until the download builds a reputation. Choose More info and then Run anyway.
